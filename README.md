# ✍️ Handwritten Character Recognition using CNN

## 📌 Overview

This project focuses on recognizing handwritten digits using a Convolutional Neural Network (CNN). The model was trained on the MNIST dataset, which contains thousands of handwritten digit images from 0 to 9. The goal is to automatically identify handwritten digits with high accuracy using Deep Learning techniques.

## 🎯 Objectives

* Recognize handwritten digits from images.
* Learn and apply Convolutional Neural Networks (CNNs).
* Perform image preprocessing and classification.
* Evaluate model performance using test data.

## 📂 Dataset

**MNIST Handwritten Digits Dataset**

* 60,000 Training Images
* 10,000 Testing Images
* Image Size: 28 × 28 Pixels
* Classes: Digits 0–9

## 🛠️ Technologies Used

* Python
* TensorFlow
* Keras
* NumPy
* Matplotlib

## 🚀 Project Workflow

1. Imported required libraries.
2. Loaded the MNIST dataset.
3. Visualized handwritten digit samples.
4. Normalized and reshaped image data.
5. Converted labels into categorical format.
6. Built a CNN architecture.
7. Compiled and trained the model.
8. Evaluated model performance.
9. Generated predictions on test images.
10. Saved the trained model.

## 📊 Results

* Successfully trained a CNN model for handwritten digit recognition.
* Achieved approximately **99.11% accuracy** on the test dataset.
* Generated accurate predictions for handwritten digits.
